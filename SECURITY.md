# Security Policy (Solvent-Labs default)

This is the org-wide default. If a repository has its own `SECURITY.md`, that
file takes precedence.

## Reporting a vulnerability

- **Preferred:** use GitHub's private vulnerability reporting ("Report a
  vulnerability" on the Security tab) of the affected repository.
- **Fallback:** email **azanhyder49@gmail.com** with a description,
  reproduction steps, and affected component.

Please do not open public issues for unpatched vulnerabilities.

## Response

- Acknowledgement within 72 hours.
- Triage and severity assessment within 7 days.
- We coordinate disclosure with the reporter; credit is given unless you
  prefer otherwise.

## Scope

Applies to all repositories under `solvent-labs-org`. Third-party
dependencies should be reported upstream; if a dependency issue materially
affects our projects, report it to us as well.
